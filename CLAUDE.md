# CLAUDE.md — Asocijacije

## Project overview

Croatian word association game built in Godot 4.6, exported to web, hosted on Firebase. Portrait-first (720×1080), programmatic UI (no .tscn scene files for game screens — everything built in GDScript).

## Architecture

```
scenes/
  main_menu.gd       — Main menu, stagger-in animations, settings overlay
  game_screen.gd     — All game logic and UI, the main file
scripts/
  puzzle_data.gd     — All puzzle content + difficulty colours
  game_state.gd      — Turn-by-turn state machine (selection, validation, scoring)
  save_manager.gd    — Persistent progress via ConfigFile
assets/
  fonts/
    Outfit-VariableFont_wght.ttf          — Primary text font
    MaterialSymbolsOutlined.ttf           — Icon font (Material Symbols)
  boot_splash.png    — Custom loading splash (replaces index.png after Godot export)
  icons/             — PNG icons at various sizes (generated by generate_icons.py)
theme/
  game_theme.tres    — Godot theme resource, all type variations defined here
export/web/          — Godot web export output (gitignored except .gitkeep)
.github/workflows/
  deploy.yml         — CI: Godot headless export → boot splash patch → Firebase deploy
```

## Key conventions

### UI is fully programmatic
No `.tscn` files for game UI. All nodes are created in GDScript (`Node.new()`, `add_child()`). This keeps diffs clean and avoids Godot's binary scene format.

### Font system
Two fonts are used together:
- **Outfit** — all Latin text (Croatian including diacritics č š ž ć đ)
- **Material Symbols Outlined** — icons via Unicode Private Use Area codepoints

Icon codepoints are defined in `_icon(name)` in `game_screen.gd` using `char(0xXXXX)` to avoid source encoding issues. Buttons that need both text and icon use `_mixed_font()` which duplicates Outfit and sets Material Symbols as its fallback — Godot falls through to the icon font for any codepoint Outfit doesn't have.

### Palette
All colours are constants at the top of `game_screen.gd` prefixed `C_`. Do not hardcode colours anywhere else.

### Animations
All tweens use `pivot_offset = size / 2.0` before scaling so nodes scale from center, not top-left. Every scale animation needs this — forgetting it causes the node to expand to the right.

### Theme variations
All text styling goes through theme type variations defined in `game_theme.tres`. Override font weight inline via `_make_font(weight)` which creates a `FontVariation` with the correct OpenType `wght` axis value.

## Puzzle data format

```gdscript
{
  "categories": [
    {
      "name": "Category name",
      "words": ["WORD1", "WORD2", "WORD3", "WORD4"],
      "difficulty": PuzzleData.Difficulty.YELLOW,  # YELLOW GREEN BLUE PURPLE
      "rank": 0,        # 0-3, used for difficulty badge stars
      "extra": ""       # Optional hint shown in solved row
    },
    # ... 3 more categories
  ]
}
```

Words are stored lowercase in data, displayed `.to_upper()` in UI.

## CI/CD pipeline

Push to `main` triggers `.github/workflows/deploy.yml`:
1. Downloads Godot 4.6 Linux headless + web export templates
2. Runs `godot --headless --export-release "Web" export/web/index.html`
3. Validates export succeeded (checks index.html exists)
4. Copies `assets/boot_splash.png` → `export/web/index.png` (Godot web export generates a Godot-logo index.png by default; we replace it)
5. Patches HTML background colour to match our dark theme
6. Deploys to Firebase Hosting via `FIREBASE_TOKEN` secret

## Known pitfalls

- **Font glyphs:** Outfit has no symbols outside Latin + Croatian. Any non-Latin character (arrows, stars, emoji) must use Material Symbols via `_icon()` + `_mixed_font()`. Never put Unicode symbols directly in button `.text` without the mixed font.
- **Scale pivot:** Always set `pivot_offset = size / 2.0` before a scale tween. Godot's default pivot is top-left.
- **Web export index.png:** Godot generates this from the project icon, not the boot splash. The CI pipeline patches it manually — do not remove that step.
- **COOP/COEP headers:** Required for SharedArrayBuffer (Godot threads). Firebase `firebase.json` sets these. Without them the game won't load.
