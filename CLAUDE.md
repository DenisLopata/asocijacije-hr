# CLAUDE.md — Asocijacije

## Project overview

Croatian word association game built in Godot 4.6, exported to web, hosted on Firebase. Portrait-first (720×1080), programmatic UI (no .tscn scene files for game screens — everything built in GDScript).

## Architecture

```
scenes/
  main_menu.gd       — Main menu, stagger-in animations, settings overlay
  game_screen.gd     — All game logic and UI, the main file
scripts/
  puzzle_data.gd     — All puzzle content + difficulty colours
  game_state.gd      — Turn-by-turn state machine (selection, validation, scoring)
  save_manager.gd    — Persistent progress via ConfigFile
assets/
  fonts/
    Outfit-VariableFont_wght.ttf          — Primary text font (variable, weights 300–800)
    MaterialSymbolsOutlined.ttf           — Icon font (Material Symbols)
  boot_splash.png    — Custom loading splash (replaces index.png after Godot export)
  icons/             — PNG icons at various sizes (generated by generate_icons.py)
theme/
  game_theme.tres    — Godot theme resource, all type variations defined here
export/web/          — Godot web export output (gitignored except .gitkeep)
.github/workflows/
  deploy.yml         — CI: Godot headless export → boot splash patch → Firebase deploy
```

## Game modes

Three modes, all accessible from the main menu:

| Mode | Puzzles | Seed | Once a day |
|------|---------|------|------------|
| **Dnevni izazov** | 1 | `YYYYMMDD` | Yes — result saved in prefs |
| **Dnevnih 5** | 5 | `YYYYMMDD + 1` | Yes — result saved in prefs |
| **Nova igra** | 5 | None (random) | No |

- Daily seeds are deterministic — all players get the same puzzle on the same date.
- "Once a day" is enforced client-side (device clock). Server-side validation via seed storage in Firestore is planned.
- Completed daily modes show "Već odigrano • score • time" and are disabled for the rest of the day.
- `SaveManager.save_daily_result` / `load_daily_result` — single puzzle daily (prefs section `daily_single`)
- `SaveManager.save_five_result` / `load_five_result` — five puzzle daily (prefs section `daily_five`)

## Game flow

- Linear puzzle order — no skipping.
- Per-puzzle timer starts on `_load_puzzle`, elapsed recorded in `_on_game_won` / `_on_game_lost`.
- Mid-session progress saved to `save.cfg` (except daily modes which never write to save).
- After the last puzzle: summary overlay → name picker → `_on_name_confirmed` → save result → menu.
- Name picker: Croatian alphabet + digits + hyphen + space, 4–10 characters, OK disabled until 4 chars entered.
- `_puzzle_times: Array[float]` and `_puzzle_scores: Array[int]` accumulate across puzzles in a session.

## Debug shortcuts

In debug builds (`OS.is_debug_build()`) only — stripped from `--export-release`:
- **Ctrl+D** on game screen: fills fake scores/times and opens name picker immediately.

## Key conventions

### UI is fully programmatic
No `.tscn` files for game UI. All nodes are created in GDScript (`Node.new()`, `add_child()`). This keeps diffs clean and avoids Godot's binary scene format.

### Font system
Two fonts are used together:
- **Outfit** — all Latin text (Croatian including diacritics č š ž ć đ). Variable font, weights 300–800.
- **Material Symbols Outlined** — icons via Unicode Private Use Area codepoints.

**Critical:** Outfit is a variable font. Always load it via `_make_font(weight)` or `_mixed_font(weight)` — never as a raw `FontFile`. A raw `FontFile` load of a variable font produces garbled glyphs in Godot because no weight axis is set.

- `_make_font(weight)` — returns `FontVariation` with Outfit at the given `wght` axis value.
- `_mixed_font(weight)` — same as `_make_font` but with Material Symbols set as `.fallbacks`. Use this on any button/label that contains both text and icon codepoints.
- `_icon_font()` — returns the raw Material Symbols `FontFile` (icons only, no Latin).
- `_icon(name)` — returns `char(codepoint)` from a const dict. Use this instead of pasting PUA characters directly into source.

The theme default font (`game_theme.tres`) is a `FontVariation` sub-resource wrapping Outfit at weight 400 — not a raw `FontFile`. This ensures anything falling through to the theme default renders correctly.

Both `main_menu.gd` and `game_screen.gd` have their own `_icon`, `_icon_font`, `_mixed_font`, `_make_font` helpers since they are separate scenes.

### Palette
All colours are constants at the top of each file prefixed `C_`. Do not hardcode colours anywhere else. `main_menu.gd` has its own palette (mirrors game_screen with additions for button styles: `C_BTN_PRIMARY`, `C_BTN_DAILY`, `C_BTN_FIVE`, `C_BTN_DONE`).

### Animations
All tweens use `pivot_offset = size / 2.0` before scaling so nodes scale from center, not top-left. Every scale animation needs this — forgetting it causes the node to expand to the right.

### Theme variations
All text styling goes through theme type variations defined in `game_theme.tres`. Override font weight inline via `_make_font(weight)`.

## Puzzle data format

```gdscript
{
  "categories": [
    {
      "name": "Category name",
      "words": ["WORD1", "WORD2", "WORD3", "WORD4"],
      "difficulty": PuzzleData.Difficulty.YELLOW,  # YELLOW GREEN BLUE PURPLE
      "rank": 0,        # 1-3, difficulty within tier
      "extra": ""       # Optional hint shown in solved row
    },
    # ... 3 more categories
  ]
}
```

Words are stored lowercase in data, displayed `.to_upper()` in UI.

- `PuzzleData.get_puzzles()` — generates 5 puzzles using weighted rank selection, seeded by current RNG state.
- `PuzzleData.get_single_puzzle()` — generates 1 puzzle with balanced weights (30/40/30). Used for Dnevni izazov.

## SaveManager

- `SAVE_PATH` = `user://save.cfg` — in-progress session (puzzles, state, timers). Cleared on session end.
- `PREFS_PATH` = `user://prefs.cfg` — persistent preferences and daily results. Never cleared.
- Daily results stored in prefs under sections `daily_single` and `daily_five`, keyed by `YYYY-MM-DD`.

## CI/CD pipeline

Push to `main` triggers `.github/workflows/deploy.yml`:
1. Downloads Godot 4.6 Linux headless + web export templates
2. Runs `godot --headless --export-release "Web" export/web/index.html`
3. Validates export succeeded (checks index.html exists)
4. Copies `assets/boot_splash.png` → `export/web/index.png` (Godot web export generates a Godot-logo index.png by default; we replace it)
5. Patches HTML background colour to match our dark theme
6. Deploys to Firebase Hosting via `FIREBASE_TOKEN` secret

- **Config:** `firebase.json` — sets COOP/COEP headers required for Godot's WebAssembly

## Known pitfalls

- **Variable font raw load:** Never use `load(FONT_PATH)` directly as a font — always wrap in `FontVariation` with explicit `wght`. Raw `FontFile` of a variable font renders garbled glyphs.
- **`_mixed_font` must return FontVariation:** The fallbacks array must be set on a `FontVariation`, not on the base `FontFile` duplicate. Old pattern (`load().duplicate() as FontFile`) broke Latin rendering.
- **Font glyphs:** Outfit has no symbols outside Latin + Croatian. Any non-Latin character must use Material Symbols via `_icon()` + `_mixed_font()`. Never put Unicode symbols directly in button `.text` without the mixed font.
- **Scale pivot:** Always set `pivot_offset = size / 2.0` before a scale tween. Godot's default pivot is top-left.
- **Web export index.png:** Godot generates this from the project icon, not the boot splash. The CI pipeline patches it manually — do not remove that step.
- **COOP/COEP headers:** Required for SharedArrayBuffer (Godot threads). Firebase `firebase.json` sets these. Without them the game won't load.
- **Daily mode never saves session:** `_is_daily` and `_is_five_daily` both skip `SaveManager.save_session` calls. The "Nastavi" button on the menu only appears for Nova igra in-progress sessions.
